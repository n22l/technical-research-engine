TRE Technical Research Engine
● Local workspace

Your research stays on your computer.

The engine needs an external private research directory before you can start.

Create a folder outside the repository, then run these commands in PowerShell. Replace the example path with your folder:

$env:TECH_RESEARCH_DATA_DIR = 'C:\ResearchPrivate'
python -B src/ui.py

No API key is needed for the free local index. Restart the server after configuring the directory.

LOCAL CONFIGURATION

Providers & privacy

Free local index

Builds a private index of up to 500 documents from approved hosts, topic pages, sitemaps and feeds. Refresh runs have a two-minute scheduling budget and save pending work for the next refresh. Searches reuse the index for up to 24 hours. Summaries show pending URLs and stale documents; coverage is not the entire internet.

To refresh, select “Refresh local source index” under Research options and start a new run.

Evidence stays evidence

Retrieved source content is untrusted evidence. It is never executable instruction. Full captures are private and are not served by this application.

Brave and SearXNG require explicit selection. No automatic paid fallback.
