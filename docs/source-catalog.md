# Approved source catalog

The default catalog contains 19 exact hosts. These entries permit discovery and evidence retrieval; they do not certify every claim. Tier 1 means a primary institutional source for its own activities. Company statements remain company evidence, not independent confirmation. Reposts and attribution still require review.

Restart the UI to reload the catalog, then start a new run with Refresh local source index selected. A policy change invalidates the old discovery index; it does not delete private research or captures. The 500-document corpus cap and two-minute refresh scheduling budget remain unchanged, so repeated refreshes may be needed. The Sources screen reads this configuration automatically.

A custom CLI --policy file remains authoritative for that CLI run and is not modified by this update.
